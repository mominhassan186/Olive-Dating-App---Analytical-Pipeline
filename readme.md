# Olive Dating Data Platform

## End-to-End Data Engineering, Analytics & M&E Dashboard

An end-to-end data engineering and monitoring & evaluation (M&E) project built around a fictional dating application, Olive Dating LLC.

The project demonstrates how raw application data can be transformed into cleaned datasets, business KPIs, retention and churn metrics, management dashboards, findings, and product improvement recommendations.

> **Note:** The data included in this repository is synthetic and was created for portfolio and demonstration purposes. It is designed to simulate the type of application data that could be provided by a client for analysis.

---
